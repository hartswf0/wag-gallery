What is LDraw?

LDraw is an open standard for LEGO CAD (1995). Bricks are text, not binary:

1 4 0 0 0 1 0 0 0 1 0 0 0 1 3001.dat

MPD bundles multiple models into one file for complex scenes.

WAG Philosophy

"Words Assemble Geometries" — The brick is a word. The scene is a sentence. The context window is a paragraph.
